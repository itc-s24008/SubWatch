## 統合のときに直してほしい所

- **α版（04-12）とつなぐ所**：04-17 は `lib/logout.ts` の `runLocalCleanup()` を呼ぶだけで、Push の解除を自分で書いていない。04-12 が `registerLocalCleanup(unsubscribeBrowserPush)` を登録すれば、削除の成功のときと応答が届かないときに、サーバーを呼ばずにブラウザの購読が消える（04-17 のコードは直さなくてよい）。統合の後に、次を確かめる：
  - `components/DeleteAccount.tsx` の後始末の順（`runLocalCleanup()` → `setFlash` → `signOut` → S-02）が、04-12 の登録した解除でも3秒以内に終わる。

- **04-12・04-14 の道具が入った後**（任意）：`tests/emulator/account-delete.test.ts` の `seedChildren` で Firestore に直接置いている webPushSubscriptions・notificationEvents を、`seedPushSubscription`・`seedNotificationEvents` に置き換えてよい。
