推測した箇所と、設計書に書いていなかった所。段階1〜2 の分（2026-11-17）。

## 推測した箇所

| 場所 | 推測した内容 | 理由 |
|---|---|---|
| `components/ui.tsx` の `PageTitle` | props は `brand?`（題の上に「SubWatch」）・`left?`（「戻る」など）・`right?`（通知のベルなど） | 開発ルールには部品の名前だけがある。図 S-04・S-06・S-05 の題の左右に物がある |
| `components/ui.tsx` の `Button` | `href` を渡すと next/link で画面を移るボタンになる。`variant` は primary・secondary・danger・dangerOutline（白地に赤い字） | 「サブスクを登録する」など、画面を移るボタンが多い |
| `components/ui.tsx` の `LinkButton` | 見た目がリンクの `<button>`（S-02 の③、S-13 の⑧） | 開発ルールの「押しても画面を移らないリンクは、見た目がリンクの button」から |
| `components/ui.tsx` の `Switch`・`RadioGroup`・`Checkbox`・`Select` の props | 各部品の上のコメントのとおり | 名前だけが決まっている |
| `components/ConsentScreen.tsx` | 仮の題は「同意の確認」 | 中身は 04-19 が書く |
| 各画面の空のページの題 | S-01「ユーザー登録」、S-03「ホーム」、S-04「サブスク一覧」、S-07「請求カレンダー」、S-08「通知センター」など | 担当が作り直す仮の題 |
| `components/Gates.tsx` | 下部ナビを `nav` という props で受け取り、S-13 を出している間は出さない | 「S-13 を出している間は下部ナビを出さない」を、layout と Gates の間で守るため |
| `lib/firebase-client.ts` | Auth Emulator の場所は `http://127.0.0.1:9099`（firebase.json の port） | ブラウザから `FIREBASE_AUTH_EMULATOR_HOST` は読めない |
| `lib/api-client.ts` | ID token が取れない（`getIdToken()` が失敗）ときは、token を付けずに呼ぶ（サーバーが 401 を返す） | 設計書に無い |
| `lib/api-client.ts` | `TIMEOUT`・`NETWORK_ERROR` の message は「応答がありませんでした」「通信できませんでした」（画面には出さない内部の文） | 設計書に文が無い |
| `lib/http.ts` | `ok()` と、エラーの応答は、それぞれで requestId を作る | 「ok() は requestId を自分で付ける」から |
| `lib/http.ts` の `readJsonBody` | 本文を読む前に、Content-Length が 100KB を超えていれば 400 | 大きい本文を全部読まないため。読んだ後も確かめる |
| `lib/logout.ts` | `logout()` は `registerBeforeLogout` の処理だけを実行する（`runLocalCleanup()` は呼ばない） | 開発ルールで別の関数として書かれている。必要なら 04-12 が両方に登録する |
| `mocks/index.ts` | サブスクの ID は `mockSubscription0001`〜（英数字20文字）。登録・変更・削除は、ページを読み直すまで覚えている | 設計書に仮の ID は無い |
| `mocks/index.ts`・`lib/account.ts`・`components/AuthProvider.tsx`・`components/Gates.tsx` | 後のタスクが足す見出し（`// ===== 04-xx：… ここに足す =====`）を置いた。04-01 が置いた仮データは「04-01 が置いた仮データ」の見出しの下 | 指示書の「タスクごとに見出しを置く」から |
| `components/IconBadge.tsx`・`components/BottomNav.tsx` | 色（薄い青の地に青い字）とアイコンの形 | 図から読んだ形 |
| `tsconfig.json` | `next build` が読む `.next/types` を含める。`npm run typecheck`（`tsconfig.typecheck.json`）は `.next` を見ない | 指示書のとおり。`next build` は tsconfig.json を使うため |
