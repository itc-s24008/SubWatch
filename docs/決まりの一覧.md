## C. 仕様（アプリの動き）

### C-1 認証のエラー
- 401 UNAUTHENTICATED：token が無い・形式違い・期限切れ・失効、ユーザーが無い・無効（後の2つが分かるのは bootstrap と DELETE /api/account だけ）。
- 503 TEMPORARILY_UNAVAILABLE：Auth への問い合わせの失敗、Firestore の UNAVAILABLE。画面はサインアウトしない。無料枠の超過は 500 RESOURCE_EXHAUSTED。
- Firebase の「メール列挙保護」は既定のまま有効にする（ログイン・再認証の失敗は、登録の有無にかかわらず auth/invalid-credential になる）。
- 書く場所：機能 API共通仕様 B71・API一覧 C37・0.実装構成 B14、画面 状態一覧 B13、CL、手順 01。

### C-2 ゲート
- onApiGate（API の結果を受ける口）が反応するのは、401 UNAUTHENTICATED、409 TERMS_RECONSENT_REQUIRED、409 ACCOUNT_NOT_INITIALIZED の3つだけ。S-01・S-02 でも反応する。401 REAUTH_REQUIRED、503、ほかの 409 では反応しない。
- Gates（画面を切り替える部品）は、(auth) の画面（S-01・S-02）では判定しない（登録の途中で S-13 に切り替えない）。
- ログアウトの購読解除の呼び出しは onApiGate を呼ばない（skipGate）。bootstrap の 409 でも onApiGate を呼ばない（S-01・S-13 が自分で扱う。C-4）。
- 書く場所：機能 API共通仕様 B71、CL、指示 04-01・04-05。
- 古い書き方：「画面のゲート（onApiGate）が反応するのは」「(auth) の画面（S-01・S-02）では、ゲートは判定しない」

### C-3 S-09 のスイッチの失敗
- isGateError のときは、文を出さずに元へ戻す。それ以外の失敗は元へ戻し、③は「変更できませんでした。もう一度お試しください」、④はオンにするとき「登録できませんでした…」、オフにするとき「解除できませんでした…」（画面設計書 S-09 の文言を正とする）。
- ④をオフにするときは、サーバーの解除（DELETE /api/push/subscribe）が成功してからブラウザの購読を解除する。サーバーが失敗したら、オンのまま「解除できませんでした…」。
- 書く場所：機能 API共通仕様 B95・B108・詳細_F-12、画面 S-09 ③④、CL。
- 古い書き方：「401・409 のときだけ失敗の文を出さずに」
